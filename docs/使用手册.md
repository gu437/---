|------|------|----------|
| `config.ts` | 站点标题、描述、base 路径、语言 | 低 |

| `palette.scss` | 颜色主题变量 | 低 |

## 二、环境搭建

### 2.1 前置条件

- **Node.js** >= 18（推荐 20）
- **pnpm** >= 8（推荐使用 pnpm）

### 2.2 安装依赖

```bash
cd /home/user/my-blog

# 安装依赖
pnpm install

# 首次安装后需要批准 esbuild 构建
pnpm approve-builds esbuild @parcel/watcher
```

### 2.3 验证安装

```bash
# 启动本地开发服务器
pnpm docs:dev
```

访问 `http://localhost:8080/---/` 查看站点。

## 三、本地开发与预览

### 3.1 启动开发服务器

```bash
cd /home/user/my-blog
pnpm docs:dev
```

启动后访问 `http://localhost:8080/---/`，支持**热更新**——修改文件后浏览器自动刷新。

### 3.2 构建生产版本

```bash
pnpm docs:build
```

构建产物输出到 `docs/.vuepress/dist/` 目录。

### 3.3 清理缓存重新构建

如果修改了配置文件后构建异常，清理缓存后重新构建：

```bash
rm -rf docs/.vuepress/dist docs/.vuepress/.temp docs/.vuepress/.cache
pnpm docs:build
```

### 3.4 使用一键部署脚本

```bash
bash deploy.sh
```

## 四、文章管理（增删改）

### 4.1 文章存放位置

所有博客文章放在 `docs/blog/` 目录下，以 `.md` 文件形式存在。

### 4.2 新增文章

**第一步：创建 Markdown 文件**

在 `docs/blog/` 目录下创建新的 `.md` 文件，例如 `my-new-article.md`：

```bash
touch docs/blog/my-new-article.md
```

**第二步：编写文章内容**

文件必须包含 **Frontmatter**（头部元信息）和正文内容：

```markdown
---
title: 文章标题
date: 2026-06-10
category: security
tags:
  - 标签1
  - 标签2
  - 标签3
excerpt: 这是文章的摘要，会显示在博客列表页。
---

# 文章标题

这里是正文内容，支持完整的 Markdown 语法。

## 二级标题

正文内容...

### 三级标题

更多内容...
```

**第三步：构建并部署**

```bash
pnpm docs:build
bash deploy.sh
```

### 4.3 删除文章

直接删除对应的 `.md` 文件即可：

```bash
rm docs/blog/要删除的文章.md
```

然后重新构建部署。

### 4.4 修改文章

直接编辑对应的 `.md` 文件，修改 Frontmatter 或正文内容均可。

### 4.5 文章分类（category）可选值

| 值 | 显示名 | 说明 |
|----|--------|------|
| `security` | 安全研究 | 渗透测试、漏洞分析、CTF |
| `tech` | 技术笔记 | 编程开发、工具使用 |
| `notes` | 学习记录 | 日常学习总结 |
| `ctf` | CTF | CTF 竞赛解题 |

> **注意：** 分类值需要与 `navbar.ts` 中的分类链接对应。如果要新增分类，需要同时修改 `navbar.ts`。

### 4.6 文章标签（tags）

标签是自由定义的，用 YAML 列表格式：

```yaml
tags:
  - Nmap
  - 渗透测试
  - 信息收集
```

标签会自动生成标签页面，无需手动维护。

### 4.7 文章排序

文章默认按 `date`（日期）倒序排列（最新的在前）。修改 `date` 字段即可控制排序。

### 4.8 星标文章

在 Frontmatter 中添加 `star: true` 可将文章标记为星标文章，会在侧边栏的"星标文章"区域显示：

```yaml
---
title: 重要文章
star: true
---
```

### 4.9 文章置顶

在 Frontmatter 中添加 `sticky` 数值可实现文章置顶，数值越大越靠前：

```yaml
---
title: 置顶文章
sticky: 100
---
```

### 4.10 草稿文章

在 Frontmatter 中添加 `draft: true` 可将文章标记为草稿，生产环境不会显示：

```yaml
---
title: 未完成的文章
draft: true
---
```

## 五、页面管理

### 5.1 首页配置

首页文件：`docs/README.md`

#### 修改首页头像

替换 `docs/.vuepress/public/avatar.png` 文件（推荐 200x200 以上正方形图片）。

#### 修改首页文字

编辑 `docs/README.md` 的 Frontmatter：

```yaml
---
home: true
layout: Blog
icon: home
title: 首页
heroImage: /avatar.png           # 头像路径
heroText: Gu437's Blog           # 主标题
tagline: 安全研究 · 技术探索 · 学习记录  # 副标题
heroFullScreen: true             # 全屏显示
bgImage: false                   # 禁用默认背景（保留动画背景）
heroImageStyle:                  # 头像样式
  border-radius: 50%
  width: 180px
  height: 180px
---
```

#### 修改首页项目卡片

编辑 `docs/README.md` 的 `projects` 字段：

```yaml
projects:
  - icon: shield-halved          # FontAwesome 图标名
    name: 安全研究               # 卡片标题
    desc: 渗透测试、漏洞挖掘     # 卡片描述
    link: /blog/category/security/  # 点击跳转链接
  - icon: code
    name: 技术笔记
    desc: 编程开发、工具使用
    link: /blog/category/tech/
  # 添加更多卡片...
```

#### 修改首页正文

编辑 `docs/README.md` 中 Frontmatter 之后的 Markdown 内容。

### 5.2 "关于我"页面

文件：`docs/intro.md`

直接编辑该文件即可修改个人介绍内容。Frontmatter 中可设置页面图标：

```yaml
---
title: 关于我
icon: user        # 页面图标（FontAwesome）
---
```

### 5.3 新增独立页面

在 `docs/` 目录下创建新的 `.md` 文件即可自动生成页面。

例如创建 `docs/projects.md`：

```markdown
---
title: 我的项目
icon: rocket
---

# 我的项目

这里是项目介绍...
```

页面访问地址为 `https://gu437.github.io/---/projects.html`。

### 5.4 删除页面

删除对应的 `.md` 文件，同时检查 `navbar.ts` 中是否有引用该页面的链接，如有则一并删除。

## 七、分类与标签管理

### 7.1 分类管理

分类通过文章 Frontmatter 中的 `category` 字段定义。

**当前分类：**

| 分类值 | 显示名 | 对应文章数 |
|--------|--------|-----------|
| `security` | 安全研究 | 自动统计 |
| `tech` | 技术笔记 | 自动统计 |
| `notes` | 学习记录 | 自动统计 |
| `ctf` | CTF | 自动统计 |

**新增分类步骤：**

1. 在 `navbar.ts` 中添加新分类的导航链接：

```typescript
{ text: "新分类名", icon: "图标名", link: "/blog/category/new-category/" }
```

2. 在文章 Frontmatter 中使用新分类值：

```yaml
category: new-category
```

3. 构建部署后，分类页面会自动生成。

**删除分类：**

1. 将使用该分类的文章的 `category` 改为其他分类
2. 从 `navbar.ts` 中删除对应导航项
3. 构建部署

### 7.2 标签管理

标签通过文章 Frontmatter 中的 `tags` 字段定义，**无需手动维护**。

```yaml
tags:
  - 标签名1
  - 标签名2
```

标签页面会自动根据所有文章的标签生成。删除某篇文章的标签后，如果没有任何其他文章使用该标签，该标签页面会自动消失。

## 九、主题与样式自定义

### 9.1 颜色主题

修改 `docs/.vuepress/styles/palette.scss`：

```scss
// 主色调（影响链接、按钮、强调色等）
$theme-color: #1e90ff;

// 暗模式背景色
$dark-bg-color: #1a1a2e;
$dark-bg-color-secondary: #16213e;
```

### 9.2 自定义样式

修改 `docs/.vuepress/styles/config.scss`，可以添加任意 CSS/SCSS 样式。

**示例：修改导航栏高度**

```scss
.navbar {
  height: 60px !important;
}
```

**示例：修改文章内容区宽度**

```scss
[vp-content]:not(.custom) {
  max-width: 900px;
}
```

**示例：修改代码块样式**

```scss
div[class*="language-"] {
  border-radius: 12px;
  border: 1px solid rgba(30, 144, 255, 0.2);
}
```

### 9.3 头像样式

头像的圆形、光环动画、hover 效果在 `config.scss` 中定义：

```scss
.home-blog-wrapper {
  .hero-info {
    .vp-blog-avatar {
      animation: avatar-glow 3s ease-in-out infinite;  // 呼吸光环
      &:hover {
        transform: scale(1.08) rotate(2deg);           // hover 放大旋转
      }
    }
  }
}
```

### 9.4 暗模式

vuepress-theme-hope 内置暗模式支持，用户可通过导航栏的太阳/月亮图标切换。

暗模式的样式适配在 `config.scss` 底部的 `html.dark` 选择器中：

```scss
html.dark {
  // 暗模式下的自定义样式
  .home-blog-wrapper {
    .hero-info {
      .vp-blog-avatar {
        animation: avatar-glow 3s ease-in-out infinite;
      }
    }
  }
}
```

1. 准备一张正方形图片（推荐 200x200 以上）
2. 替换 `docs/.vuepress/public/avatar.png`

### 10.3 替换 Favicon

1. 准备一个 `.ico` 格式的图标文件（推荐 32x32 或 16x16）
2. 替换 `docs/.vuepress/public/favicon.ico`
3. 重新构建部署

### 10.4 添加图片到文章

**方式一：使用 public 目录**

将图片放入 `docs/.vuepress/public/images/` 目录（需手动创建），然后在文章中引用：

```markdown
![图片描述](/images/my-image.png)
```

**方式二：使用相对路径**

将图片放在文章同级目录下，使用相对路径引用：

```markdown

```

将文件放入 `docs/.vuepress/public/downloads/` 目录，在文章中链接：

```markdown

```

## 十一、动画背景管理

### 11.1 动画背景组件

山水动画背景在 `docs/.vuepress/client.ts` 中定义，通过 `rootComponents` 注入到页面根层。

### 11.2 禁用动画背景

如果想禁用动画背景，修改 `docs/.vuepress/client.ts`：

```typescript
export default defineClientConfig({
  rootComponents: [],  // 清空即可禁用
});
```

同时修改 `docs/.vuepress/styles/config.scss`，删除透明背景样式：

```scss
// 删除以下内容：
html, body, .vp-page, .vp-blog, .home-blog-wrapper, .vp-blog-home {
  background: transparent !important;
}
.vp-blog-mask {
  display: none !important;
}
```

### 11.3 恢复默认背景图

如果禁用动画背景后想使用 vuepress-theme-hope 默认的山峦背景图，修改 `docs/README.md`：

```yaml
---
# 删除 bgImage: false，或改为：
bgImage: /bg/1-light.svg    # 浅色模式背景
# bgImage: /bg/1-dark.svg  # 深色模式背景
---
```

### 11.4 修改动画效果

动画的核心参数在 `client.ts` 的 `mountainLayers` 数组中：

```typescript
const mountainLayers = [
  { color: "#1a1a2e", height: 0.35, speed: 0.02, amplitude: 80, frequency: 0.003 },
  { color: "#16213e", height: 0.40, speed: 0.04, amplitude: 70, frequency: 0.004 },
  // ...
];
```

| 参数 | 说明 |
|------|------|
| `color` | 山脉颜色（十六进制） |
| `height` | 山脉基线高度（0-1，越大越靠下） |
| `speed` | 视差移动速度 |
| `amplitude` | 山峰起伏幅度 |
| `frequency` | 山峰波动频率 |

## 十二、部署上线

### 12.1 部署方式

本站使用 **gh-pages 分支部署**：将构建产物推送到 `gh-pages` 分支，GitHub Pages 从该分支提供服务。

### 12.2 一键部署

```bash
cd /home/user/my-blog

# 方式一：使用部署脚本
bash deploy.sh

# 方式二：手动部署
pnpm docs:build
git add -f docs/.vuepress/dist/
git commit -m "deploy: 更新构建产物"
git subtree split --prefix=docs/.vuepress/dist --branch gh-pages-deploy
git push origin gh-pages-deploy:gh-pages --force
git branch -D gh-pages-deploy
```

### 12.3 完整部署流程

```bash
# 1. 确保代码已提交
git add .
git commit -m "feat: 新增文章 xxx"

# 2. 清理缓存并构建
rm -rf docs/.vuepress/dist docs/.vuepress/.temp docs/.vuepress/.cache
pnpm docs:build

# 3. 设置远程仓库（带 Token）
git remote set-url origin https://gu437:<TOKEN>@github.com/gu437/---

# 4. 创建部署分支并推送
git add -f docs/.vuepress/dist/
git commit -m "deploy: 更新"
git subtree split --prefix=docs/.vuepress/dist --branch gh-pages-deploy
git push origin gh-pages-deploy:gh-pages --force
git branch -D gh-pages-deploy

# 5. 清理远程 URL（移除 Token）
git remote set-url origin https://github.com/gu437/---

# 6. 等待 1-2 分钟后访问 https://gu437.github.io/---/
```

### 12.4 GitHub Pages 设置

在 GitHub 仓库的 **Settings → Pages** 中：

- **Source：** Deploy from a branch
- **Branch：** `gh-pages` / `/ (root)`

### 12.5 PAT Token 管理

部署需要 GitHub Personal Access Token（PAT），权限要求：

- `repo`（仓库读写）
- `workflow`（可选，如果使用 GitHub Actions）

如果 Token 过期，到 https://github.com/settings/tokens 重新生成。

## 十三、常见问题排查

### 13.1 构建失败

**问题：** `pnpm docs:build` 报错

**解决：**

```bash
# 清理缓存重新构建
rm -rf docs/.vuepress/dist docs/.vuepress/.temp docs/.vuepress/.cache node_modules
pnpm install
pnpm approve-builds esbuild @parcel/watcher
pnpm docs:build
```

### 13.2 新增文章不显示

**可能原因：**

1. Frontmatter 格式错误（检查 YAML 语法）
2. `draft: true` 被设置
3. `date` 日期格式不正确
4. 构建缓存未清理

**解决：** 清理缓存重新构建。

### 13.3 页面显示 404

**可能原因：**

1. `base` 路径配置不正确
2. 文件路径大小写不匹配
3. `.nojekyll` 文件丢失

**解决：** 检查 `config.ts` 中的 `base` 配置是否与仓库名一致。

### 13.4 样式不生效

**可能原因：**

1. SCSS 语法错误
2. 选择器优先级不够（需要 `!important`）
3. 缓存未清理

**解决：** 检查浏览器控制台是否有 CSS 错误，清理缓存重新构建。

### 13.5 动画背景不显示

**可能原因：**

1. `bgImage` 未设置为 `false`
2. CSS 背景色覆盖了 canvas
3. 浏览器缓存了旧版本

**解决：**

1. 检查 `docs/README.md` 中是否有 `bgImage: false`
2. 检查 `config.scss` 中是否有透明背景样式
3. 强制刷新浏览器（Ctrl+Shift+R）

### 13.6 部署后页面未更新

**可能原因：**

1. GitHub Pages CDN 缓存（通常 1-10 分钟自动刷新）
2. 浏览器缓存
3. gh-pages 分支未正确更新

**解决：**

```bash
# 检查 gh-pages 分支内容
git log --oneline gh-pages -3

# 强制刷新浏览器
# Chrome: Ctrl+Shift+R
# Firefox: Ctrl+F5
```

### 13.7 水合错误（Hydration Mismatch）

**现象：** 控制台报 `Hydration completed but contains mismatches`

**原因：** SSR 渲染的 HTML 与客户端渲染不一致

**影响：** 不影响功能，仅控制台警告

**解决：** 使用纯客户端组件（如当前 `client.ts` 中的 MountainBg 实现）避免此问题。

## 附录 A：完整 Frontmatter 字段参考

### 文章 Frontmatter

```yaml
---
# ===== 必填字段 =====
title: 文章标题                    # 文章标题
date: 2026-06-10                  # 发布日期（YYYY-MM-DD）

# ===== 分类与标签 =====
category: security                # 分类（security/tech/notes/ctf）
tags:                             # 标签列表
  - 标签1
  - 标签2

# ===== 可选字段 =====
excerpt: 文章摘要                  # 摘要（显示在列表页）
sticky: 100                       # 置顶权重（越大越靠前）
star: true                        # 是否星标
draft: false                      # 是否草稿（true 则不发布）
author: Gu437                     # 作者（默认使用全局配置）
icon: pen                         # 页面图标
cover: /images/cover.jpg          # 文章封面图

# ===== 元信息 =====
head:                             # 自定义 head 标签
  - - meta
    - name: keywords
      content: 关键词1, 关键词2
---
```

### 页面 Frontmatter

```yaml
---
title: 页面标题                    # 页面标题
icon: user                        # 页面图标
# home: true                      # 是否为首页
# layout: Blog                    # 布局类型
---
```

### 首页 Frontmatter

```yaml
---
home: true                        # 标记为首页
layout: Blog                      # 使用博客布局
icon: home                        # 图标
title: 首页                       # 标题

heroText: Gu437's Blog            # 主标题
tagline: 副标题                    # 副标题
heroFullScreen: true              # 全屏模式
bgImage: false                    # 禁用默认背景图
heroImageStyle:                   # 头像样式
  border-radius: 50%
  width: 180px
projects:                         # 项目卡片
  - icon: shield-halved
    name: 项目名
    desc: 项目描述
    link: /链接/
---
```

## 附录 D：修改站点 base 路径

如果仓库名变更，需要同步修改 `config.ts` 中的 `base`：

```typescript
export default defineUserConfig({
  base: "/新仓库名/",  // 必须以 / 开头和结尾
});
```

修改后需要**清理缓存重新构建**，并更新所有文章中的绝对路径引用。
